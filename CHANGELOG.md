# История изменений

## 1.0.1

### Система скриптов

Добавлена система административных скриптов для событий аукциона. Все настройки вынесены в отдельный файл `plugins/AternumAuction/scripts.yml`, а не в `config.yml`.

- Готовые примеры: `plugins/AternumAuction/scripts/examples.yml` (12 скриптов с комментариями).
- Свои скрипты можно добавить в любой `.yml` файл папки `scripts/` — файлы загружаются автоматически. Файлы с префиксом `disabled-` или `_` игнорируются.
- Доступные события (`hooks`): `list`, `purchase`, `bid`, `expire`, `request`, `remove`.
- Действия скрипта:
  - `when` — условие выполнения;
  - `commission` — комиссия, удерживаемая из выплаты продавцу;
  - `deny` + `reason` — отмена операции с сообщением игроку;
  - `message`, `broadcast`, `log` — сообщения и запись в консоль;
  - `command` — команда консоли (только при `settings.allow-commands: true`).
- Переменные: `%price%`, `%total%`, `%amount%`, `%item%`, `%material%`, `%model%`, `%currency%`, `%currency_name%`, `%type%`, `%category%`, `%seller%`, `%buyer%`, `%auction_id%`, `%hour%`, `%date%`, `%weekday%` и другие.
- Выражения: `+ - * / %`, скобки, сравнения, `&& || !`, функции `min`, `max`, `round`, `floor`, `ceil`, `abs`, `sqrt`, `clamp`, `contains`, `startswith`, `lower`, `upper`, `length`, `if`.
- Безопасность: собственный парсер выражений, без `eval`, доступа к файлам, сети и Java API. Комиссия может зачисляться на `treasury-uuid` или просто изыматься из оборота.

Пример включения:

```yaml
hooks:
  purchase:
    - commission_10_percent
```

После правки выполните `/ah reload`.

### Исправления

- Закрыт обход прав: подкоманды `/ah mine`, `/ah expired`, `/ah history`, `/ah limit`, `/ah currency`, `/ah categories` теперь проверяют разрешения.
- Исправлено сбрасывание пользовательских GUI-настроек при каждом `/ah reload`: версии встроенных лэйаутов приведены к единой метке.
- Проверка цены после `AuctionPrePurchaseEvent`: `NaN`, бесконечность и значения вне диапазона больше не принимаются.
- Карты открытых меню и ожидающего чата переведены на потокобезопасные реализации (актуально для Folia).
- Устранено состояние гонки при подсчёте просмотров лота.
- Везде указана локаль `ENGLISH` для регистронезависимых операций (защита от турецкой локали).
- Комментарии в файлах ресурсов переведены на русский язык.

### Совместимость

Конфигурация 1.0.0 сохраняется: старые `config.yml`, `categories.yml`, языки и GUI продолжают работать. Новый файл `scripts.yml` создаётся автоматически при первом запуске.
