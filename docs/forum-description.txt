AternumAuction 1.0.0

Многофункциональный аукцион для Bukkit / Spigot / Paper / Folia

AternumAuction — гибкая торговая площадка для Minecraft-серверов, которая объединяет несколько типов аукциона, разные валюты, удобный GUI и безопасную обработку сделок в одном плагине.

Плагин подходит как для небольшого Survival-сервера, так и для большой сети серверов. Интерфейс, категории, кнопки, тексты, слоты и действия полностью настраиваются через YAML без пересборки плагина.

 ТРИ ТИПА АУКЦИОНА
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. BIN — фиксированная цена

Обычная продажа «купить сейчас». Продавец задаёт цену, покупатель сразу получает предмет после подтверждения сделки.

2. BID — аукцион со ставками

Продавец задаёт стартовую цену и шаг ставки. Игроки перебивают ставки друг друга, предыдущая ставка возвращается, а после окончания аукциона победитель получает предмет.

3. BUY_REQUEST — запрос на скупку

Игрок создаёт запрос на покупку нужного предмета. Другие игроки могут выполнить запрос полностью или частично и получить оплату. Средства резервируются, а невыполненная часть запроса остаётся активной.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 ГИБКАЯ НАСТРОЙКА GUI
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Каждое меню находится в отдельном YAML-файле. Можно изменить:

• количество рядов и размер страницы;
• слоты лотов и кнопок;
• названия и описание предметов;
• кастомные головы через Base64-текстуры;
• материалы, количество, зачарования и свечение;
• условия показа элементов;
• переходы между меню и действия кнопок;
• сортировку, категории и переключатели типов аукциона;
• тексты и сообщения без изменения исходного кода.

Основные файлы меню:

[CODE]
main-gui.yml          главное меню аукциона
my-items-gui.yml      мои лоты
history-gui.yml       история операций
expired-gui.yml       истёкшие лоты и выплаты
categories-gui.yml    категории
confirm-gui.yml       подтверждение сделки
currency-gui.yml      выбор валюты
shulker-gui.yml       содержимое шалкера
admin-gui.yml         меню администратора
[/CODE]

После изменений меню можно обновить без перезапуска:

[CODE]
/ah reload
[/CODE]

 ВАЛЮТЫ И ЭКОНОМИКА
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Поддерживаются:

• Vault и совместимые экономики;
• RoyaleEconomy и UltraEconomy через Vault;
• KingdomsX через Vault;
• PlayerPoints;
• CoinsEngine;
• опыт;
• уровни;
• предметная валюта из конфигурации.

Для валют с включённым `allow-offline` деньги попадают в очередь выплат и доступны после входа игрока. Предметы для офлайн-игроков сохраняются в claims и выдаются через меню «Истёкшие лоты».

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 БЕЗОПАСНОСТЬ СДЕЛОК
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

• атомарное резервирование лота при покупке;
• защита от повторной продажи одного лота;
• возврат перебитых ставок;
• возврат предмета при снятии собственного лота;
• проверка места в инвентаре;
• защита от покупки собственного объявления;
• возвраты через очередь выплат при временной ошибке экономики;
• сохранение предметов и денег для офлайн-игроков;
• автоматическая обработка истечения лотов;
• ручная очистка старых лотов администратором через `/ahadmin purge`.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 КОМАНДЫ ИГРОКА
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[CODE]
/ah                         открыть аукцион
/ah sell [цена] [кол-во]    выставить предмет из руки по фиксированной цене
/ah bid [цена] [кол-во]     создать аукцион со ставками
/ah buy [цена] [кол-во]     создать запрос на скупку предмета из руки
/ah view <игрок>            посмотреть лоты игрока
/ah mine                    открыть свои лоты
/ah history                 открыть историю операций
/ah expired                 открыть истёкшие лоты и выплаты
/ah categories              открыть категории
/ah limit                   посмотреть свой лимит лотов
/ah currency [id]           выбрать валюту
/ah reload                  перезагрузить конфигурацию
/ah help                   открыть помощь
[/CODE]

 АДМИНИСТРАТИВНЫЕ КОМАНДЫ

Конвертер поддерживает AternumAuction, zAuctionHouse, AuctionHouse, AxAuctions и DeluxeAuctions. Для внешних SQLite-баз импорт выполняется по найденной схеме; такие лоты импортируются как BIN, если исходные типы нельзя надёжно определить.

 ПРИМЕР КОНФИГУРАЦИИ

[CODE]
settings:
  language: ru
  default-duration-hours: 48
  max-duration-hours: 168
  min-price: 1.0
  max-price: 1000000000.0
  bid-step: 1.0
  tax-percent: 0.0
  allow-bin: true
  allow-bidding: true
  confirm-purchase: true

server:
  id: 'survival-1'
  multi-server:
    enabled: false
    sync-interval-seconds: 20
    show-all-servers: false

storage:
  type: yaml
  sqlite-file: data.db

currencies:
  default: vault
  remember-selection: true
  selection-gui: true
[/CODE]

Для большого проекта можно включить SQLite или MySQL. В мультисерверном режиме общие лоты синхронизируются между серверами, а покупка одного и того же объявления с двух серверов блокируется атомарной операцией.

6. Выполните /ah reload.
[/CODE]
